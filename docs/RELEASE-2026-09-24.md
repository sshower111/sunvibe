# Release: unified menu editing, SEO, and chatbot removal

Date: September 24, 2026. Production: https://sunvillebakerylv.com
Previous release: a84f104. Target branch: main (Vercel Git deployment).

## Customer and admin changes

- Both `/admin` and `/admin/menu` have one **Edit item** dialog for name, description and USD price, with one **Save changes** action. Failed saves retain the draft. Successful saves update the admin row and invalidate the public menu cache.
- Removed chatbot embed/config, identity API, client helper, CSS and CSP host permissions. Contact and custom-cake inquiries remain available.
- Public content and menu products render on the server. Added local page H1s, correct canonicals, unique metadata, a 1200×630 social card, Bakery/geo, cake Product/Offer and breadcrumb schemas, complete sitemap and private-page noindex.
- Improved image sizing, responsive hero/gallery delivery, descriptive gallery controls, landmarks and keyboard skip navigation.
- Preserved the production Blob gallery store, upload endpoints, admin feedback and client refresh from `/api/gallery`. Unknown uploaded image hosts use ordinary image delivery rather than an unrestricted optimizer. Intentional empty galleries stay empty.

## Verification before release

- Production checkout build passed. Existing configuration skips full type/lint checks; historical Stripe version/admin-gallery typing issues are documented in the audit.
- Mocked Stripe endpoint tests passed: auth, input limits, exact cents, combined writes, unchanged-price reuse, blank descriptions, failures, stable retry keys and cache invalidation. No real item edits or payments were made.
- Production-build browser tests passed for both admin editors at mobile width.
- SEO suite passed on the release build: five public routes without JavaScript, titles/canonicals/social metadata/JSON-LD, private noindex, sitemap/robots, actual social PNG dimensions, keyboard/menu behavior, and no horizontal overflow.
- axe-core reported zero WCAG A/AA violations for five public pages at 390px and 1280px in their initial states. This is not comprehensive assistive-technology certification.
- Managed-gallery regression checks passed for loaded API images, an upload host outside the optimizer allowlist, and empty gallery state.
- Chatbot endpoint returns 404 and no chatbot requests/config/CSP permissions remain.

## Operations and limits

No migrations or new environment variables. Existing Stripe, Turnstile, email and Blob settings remain required. No live customer form submission was used for validation. Vercel may retain an unused CHATBASE_SECRET_KEY; it has no runtime consumer. External subscription cancellation was not performed.

Price changes create a replacement Stripe price and switch it together with name/description in one product update. Old prices remain for history/checkout compatibility. A failed product update can leave an unused replacement price; retrying the same draft reuses its operation key. Non-USD/recurring/tiered billing must be edited in Stripe.

Catalog cache: 60-second revalidation, immediately invalidated by the new editor. An already-open customer tab must refresh to show edits. The existing visibility/legacy APIs retain their prior behavior.

The live gallery can include owner-managed photos without individual descriptions in its data model; unknown photos use an honest generic description. Field Core Web Vitals and Google rich-result eligibility require post-release monitoring; local checks do not establish field performance.
