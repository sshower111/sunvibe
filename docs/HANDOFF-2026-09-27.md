# Handoff and cleanup — September 27, 2026

Keith has moved maintenance of this project from Codex to Claude. This release is based on `release/mobile-ux-20260922` (same commit as `origin/main`, 8ccaf59).

Deployed to production in commit 8dc47ea after `pnpm build`, local and live smoke tests at 390px (menu search, admin sign-in and edits, gallery, custom cakes, pre-order). `/menu` renders per request because prerendering it timed out on the database at build time.

## Security

- Admin sign-in now uses an httpOnly, signed session cookie (12 hours, SameSite=Strict) from `/api/admin/verify`. The password is no longer kept in `localStorage`, and the old stored copy is erased the next time the admin page loads. Changing `ADMIN_PASSWORD` signs out every session. `ADMIN_SESSION_SECRET` is optional extra key material.
- All admin APIs use `isAdminRequest()` in `lib/occasion-admin.ts`, which accepts the cookie or the password for scripts. This replaces the old `password !== ADMIN_PASSWORD` checks, which let a request in when the environment variable was missing.
- `/api/check-env` now returns 404. It used to expose the notification email address.
- The old `/admin/gallery` page (which checked `NEXT_PUBLIC_ADMIN_PASSWORD` in the browser) and the old `/admin/menu` page now redirect to `/admin`. **If `NEXT_PUBLIC_ADMIN_PASSWORD` exists in Vercel, delete it.**
- The maintenance POST endpoint was removed because it never changed anything. Settings now shows the status and explains how to change it.

## Usage and cost

- `middleware.ts`: only form and admin pages (`/admin`, `/contact`, `/custom-cakes`, `/pre-order`, `/checkout`) get a nonce CSP and render on every request. Home, menu, gallery and privacy use a fixed CSP (`'unsafe-inline'` scripts, no user input on these pages), so they are cached and served from the CDN with `revalidate = 900` in the root layout. `StructuredData` no longer calls `headers()`, which had made every page dynamic.
- Home and gallery render the gallery on the server through `lib/public-gallery.ts`. Browsers no longer call `/api/gallery` on each visit.
- The database migration marker is checked once per server instance instead of before every query (`verifiedDatabase()`).
- The menu and gallery caches last 24 hours and are cleared immediately by admin edits. Failed reads are not cached.
- Menu thumbnails, the About photo and the custom-cake photos use `next/image`. Supabase photo URLs are recognised through `NEXT_PUBLIC_PHOTO_BASE`, which is set in `next.config.mjs`. There are fewer image sizes, WebP only, and a 31-day optimizer cache.
- Removing a gallery photo deletes the Supabase file unless a menu item, occasion or the gallery still uses it (`deletePhotoIfUnused`).
- `/og` is generated at build time.
- The cart provider now loads only under `/checkout` (legacy Stripe flow), not on every page.

## UI/UX

- **Admin is rebuilt for phones:** a sticky header, sideways-scrolling tabs, menu items as cards with search and a Visible/Hidden filter, a two-step remove for photos, and messages inside the page instead of `alert()`.
- **Menu search:**
  - Enter runs the search without picking a suggestion. It closes the keyboard and scrolls to the results.
  - Search tolerates typos, so "moncake" finds mooncake. Close matches are only used when a word has no exact match, and they are labelled "close matches".
  - Suggestions are limited to 8.
- **Menu on mobile:** one fixed Call / Directions bar replaces the repeated call buttons.
- **Custom cakes:**
  - Removed the "Sizes & prices" button that sat right above that section.
  - "Compare sizes" shows only the selected style.
  - The delivery fee rows are evenly spaced.
  - Added a row of real cake photos beside the inquiry form.
- **Site-wide:** "Pre-order" appears in the navigation while a campaign is active. A banner dismissed in the last 24 hours no longer flashes on load (on read-only pages).
