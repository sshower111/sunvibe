## Admin description editing
Open /admin, choose Menu, then Edit Description under an item. Save updates that product in Stripe; refresh the public menu to see it. Blank descriptions remove existing text. Limit: 2,000 characters. The endpoint requires the existing server-side ADMIN_PASSWORD. No new environment variables.
